# 01. 요구사항 (Requirements) — 채팅 UI

> 인터뷰 영역 4·7 (범위·MVP / 제약·비기능) 정리 · 상태: draft

## 범위 — MoSCoW
| 구분 | 항목 | 근거 |
|------|------|------|
| **Must** | 텍스트 질문 전송 + SSE 스트리밍 답변 | REQ-F-001, REQ-F-002 |
| **Must** | 도구 호출 진행 상태 표시 | REQ-F-003 |
| **Must** | 채팅창 파일 업로드(file-converter 연동) + 결과 다운로드 | REQ-F-004, REQ-F-005 |
| Should | 도구 호출 실패 시 에러 메시지 명확히 표시 | REQ-F-006 |
| Could | 채팅 로그 텍스트로 내보내기(발표 후 공유용) | REQ-F-007 |
| **Won't (MVP 제외)** | 멀티턴 대화(히스토리 유지) — **명시적으로 사용 안 함**, 로그인/인증, 모바일 반응형, 다국어 | 범위 통제 |

## 기능 요구사항 (REQ-F-*)
| ID | 요구사항 | 우선순위 | 관련 SCR/FLOW |
|----|----------|:--------:|---------------|
| REQ-F-001 | 사용자는 텍스트 질문을 입력해 어시스턴트에게 보낼 수 있다 | Must | FLOW-001 · SCR-001 |
| REQ-F-002 | 사용자는 답변을 실시간 스트리밍(SSE)으로 받는다 | Must | FLOW-001 · SCR-001 |
| REQ-F-003 | 사용자는 도구 호출 진행 상태(예: "KBO 에이전트 호출 중")를 확인할 수 있다 | Must | FLOW-001 · SCR-001 |
| REQ-F-004 | 사용자는 채팅창에 파일을 드래그·업로드해 file-converter에 넘길 수 있다 | Must | FLOW-002 · SCR-001 |
| REQ-F-005 | 사용자는 변환된 파일을 다운로드할 수 있다 | Must | FLOW-002 · SCR-001 |
| REQ-F-006 | 도구 호출/변환 실패 시 원인과 재시도 방법을 명확히 안내한다 | Should | SCR-001 (error) |
| REQ-F-007 | 채팅 로그를 텍스트로 내보낼 수 있다 | Could | — |

## 비기능 요구사항 (REQ-NF-*)
| ID | 항목 | 기준 |
|----|------|------|
| REQ-NF-001 | 플랫폼 | 데스크톱 웹 브라우저(최신 Chrome 기준), 모바일 대응 안 함 |
| REQ-NF-002 | 오프라인 | 미지원 — 항상 서버(FastAPI) 연결 필요 |
| REQ-NF-003 | 프라이버시/규정 | 업로드 파일은 서버에 영구 저장하지 않음(변환 후 임시파일 삭제) |
| REQ-NF-004 | 성능/응답성 | SSE로 첫 청크까지 체감 지연 최소화 — 도구 호출 상태 표시로 "멈춘 것처럼" 안 보이게 함 |
| REQ-NF-005 | 접근성 | 최소 수준(색 대비만 확보) — 스크린리더 등 심화 대응은 Won't |

## 제약
- 기술 스택: 순수 HTML/CSS/JS + FastAPI 정적 파일 서빙(빌드 도구 없음)
- 일정: 8/14 발표 전까지
- 되돌릴 수 없는 동작: 없음(읽기·변환 위주, 삭제 없음 — 확인 절차 불필요)
