# 00. 프로젝트 브리프 — 채팅 UI

> 인터뷰 영역 1~3 (문제·목표 / 사용자·맥락 / 가치·성공 지표) 정리
> 작성일: 2026-08-11 · 상태: draft

## 한 문장 정의
이 웹 채팅 화면은 발표자가 AI 어시스턴트(Main LLM + Tech/Code/General 도구)와 텍스트·파일로 상호작용하며, 도구 호출 과정을 실시간으로 확인하도록 돕는다.

## 문제 · 목표 (왜)
- **푸는 문제:** 지금은 도구(file-converter 등)를 `curl`이나 FastAPI `/docs`(Swagger UI)로만 호출 가능 — 8/14 발표 시연에 부적합하고, 도구가 늘어날수록 흩어짐
- **현행 대안:** FastAPI `/docs`로 API 하나씩 개별 테스트
- **성공 시 변화:** 발표에서 실제 채팅 화면으로 "질문 → 도구 호출 과정 → 답변"을 한 화면에서 시연 가능

## 대상 사용자 · 맥락
| 항목 | 내용 |
|------|------|
| 1차 사용자 | 발표자/시연자(팀원 본인) |
| 2차 사용자/수신자 | 심사자·청중(화면을 보는 사람) |
| 사용 맥락 | 8/14 발표, 노트북 화면, 데스크톱 브라우저, 짧은 시연(수 분) |

## 핵심 가치 · 성공 지표
- **핵심 가치:** 어떤 도구가 어떻게 동작했는지 눈에 보이는 AI 어시스턴트 데모
- **성공 지표:** 발표에서 최소 1개 이상의 질문→답변 흐름을 에러 없이 시연 완료
- **반드시 지킬 품질:** 스트리밍 응답이 끊기지 않고, 도구 호출 상태가 화면에 명확히 표시됨

## 비전 대비 MVP 경계 (요약)
MVP는 **단일 턴 채팅(텍스트) + 파일 업로드(file-converter 연동) + 도구 호출 상태 표시**까지. 멀티턴 대화, 모바일 대응, 로그인/인증은 의도적으로 제외 — [01_requirements.md](01_requirements.md) Won't 참조.
