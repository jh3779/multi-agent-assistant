# YouTube 자막 기반 답변 확인용 설계

> **상태(2026-11-26 확인): 미구현 설계.** 이 설계가 전제하는 `youtube_search`·`youtube_transcript` 도구와 `TechAgent` 연동은 현재 `main` 코드에 존재하지 않는다(`TechAgent`의 도구는 웹 검색뿐, `app/llms/tech.py`). 설계 기록으로만 보존한다.

## 목적

`TechAgent`가 영상 정보가 필요하다고 판단할 때 기존 도구를 사용해 유튜브를 검색하고, 선택한 영상의 자막을 조회한 뒤, 자막 내용을 근거로 답변하는지 확인한다.

## 변경 범위

- `TechAgent`의 시스템 프롬프트에 `youtube_search` → `youtube_transcript` → 자막 기반 답변 순서를 명시한다.
- 도구 호출 여부와 검색 결과 중 영상 선택은 에이전트가 판단한다.
- 기존 `create_agent` 구성과 유튜브 도구 구현은 변경하지 않는다.
- 외부 API를 호출하지 않는 작은 테스트로 프롬프트 규칙을 확인한다.

## 동작

1. 에이전트가 질문에 영상 정보가 필요한지 판단한다.
2. 필요하면 `youtube_search`를 호출한다.
3. 관련 영상의 `video_id`로 `youtube_transcript`를 호출한다.
4. 검색 결과의 제목·설명만이 아니라 조회한 자막을 근거로 답변한다.
5. 도구가 필요하지 않은 질문은 도구 없이 답변할 수 있다.

## 제외 범위

- LangGraph 기반의 강제 실행 순서
- 검색·자막 조회를 합친 새 복합 도구
- 외부 YouTube/OpenAI API를 사용하는 통합 테스트
- 자막 실패 시 재시도 정책
