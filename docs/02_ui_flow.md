# 02. UI Flow — 채팅 UI 사용자 경로 · 화면 목록

> 인터뷰 영역 5 정리 · 상태: draft

## 화면 목록 (SCR-*)
단일 페이지 앱 — 화면은 사실상 1개.

| ID | 화면 | 목적 | 주요 상태 |
|----|------|------|-----------|
| SCR-001 | 채팅 화면 | 질문/파일 전송, 도구 호출 과정·답변 확인 | empty / sending / tool-active / streaming / error |

## 주요 플로우 (FLOW-*)

### FLOW-001 · 텍스트 질문 → 답변
```
ENTRY(페이지 로드) → SCR-001(empty) ─[질문 입력+전송]→ SCR-001(sending)
  ─[SSE 연결]→ SCR-001(tool-active, 도구 상태 표시) ─[스트리밍 완료]→ SCR-001(답변 표시, 입력창 재활성화)
                                                    └─[전송/서버 오류]→ SCR-001(error, 재시도 버튼)
```
- 진입점: 페이지 로드 직후 입력창에 포커스
- 분기: 도구 호출이 필요 없는 질문이면 tool-active 단계 생략하고 바로 streaming
- 예외/복구: 네트워크 끊김·서버 5xx → error 상태 + 재시도 버튼(직전 질문 재전송)

### FLOW-002 · 파일 업로드 → 변환 → 다운로드
```
ENTRY(채팅 화면) → SCR-001 ─[파일 드래그/선택 + target_format 지정]→ SCR-001(uploading)
  ─[file-converter 호출 성공]→ SCR-001(변환 완료, 다운로드 링크 표시)
                              └─[지원 안 하는 포맷/실패]→ SCR-001(error, 지원 포맷 안내)
```
- 진입점: 채팅 입력창 옆 파일 업로드 영역(드래그 앤 드롭 가능 표시)
- 분기: 대상 포맷은 `GET /tools/file-converter/formats` 목록에서 선택
- 예외/복구: `UnsupportedFormatError` → 지원 포맷 안내 문구로 즉시 표시(서버 왕복 후)

## 네비게이션 스택 전략
단일 화면이라 스택 개념 없음. "새 대화 시작" 버튼은 화면의 메시지 로그만 초기화 — 멀티턴이 아니므로 서버 쪽에 지울 세션 상태가 없음.
